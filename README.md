# Vitor Galache

Desenvolvedor back-end com foco no ecossistema .NET, atuando na construção de APIs robustas com ASP.NET Core e aplicando boas práticas de arquitetura de software — Clean Architecture, DDD e CQRS. Tenho experiência com bancos relacionais e NoSQL, escrita de testes automatizados e uso de Redis para cache e mensageria.

Também possuo conhecimentos de front-end e já trabalhei com Blazor. Busco oportunidades onde possa contribuir com soluções reais e continuar evoluindo tecnicamente.
