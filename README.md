# Vitor Galache

Desenvolvedor back-end .NET, com foco na construção de APIs robustas e escaláveis, aplicando princípios de arquitetura limpa e modelagem orientada a domínio. Experiência com sistemas orientados a mensageria e eventos, comunicação em tempo real, estratégias de cache e cultura de testes automatizados integrada ao ciclo de desenvolvimento. Atuação também em desenvolvimento de interfaces front-end quando o projeto exige.
